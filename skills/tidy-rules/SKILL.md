# ルールの棚卸し

ぶつかる禁止は両方とも守れず、出力が中途半端になる。それを直そうとルールを足すと、またぶつかる。このループを止めるため、足す前に、消す・書き直す・置き直すを考える。

## 足す前（毎回）

メモリや AGENTS.md にルールを足す前に、同じ話題の既存のルールを探す。

- `agentlog rules --repo .`：このディレクトリのセッションが読む禁止（グローバル・リポジトリ・このプロジェクトのメモリ）
- `agentlog memory 'REGEX'`：ほかのプロジェクトのメモリ

同じ話題があれば、足さずにそれを書き直す。無いときだけ足す。足すときは、いつ効くか（条件）と理由（`Why:`）を書く。理由があれば、ぶつかったときにどちらの目的を取るかを選べる。

## 棚卸し（頼まれたとき、振る舞いがおかしいとき）

1. **材料を出す.** `agentlog rules --repo <DIR> --json` で、グローバル（`~/.claude/CLAUDE.md`）、そのリポジトリの AGENTS.md・CLAUDE.md、そのプロジェクトのメモリを出す。全プロジェクトのメモリも見るなら、`--repo` を外したもの（`agentlog rules --json`。メモリだけで、グローバルとリポジトリの分は入らない）も出し、2回分を合わせて見る（そのプロジェクトのメモリは両方に出る）。Codex も見るなら、どちらにも `--source all`。数えるのは機械だが、判定は緩い（「〜ない」で終わる行はほぼ拾う）ので、禁止でない行は読み飛ばす。
2. **1ルールずつ、4つを見る.**
   - **有効か**：書いたときの状況（日付、プロジェクトの段階、一時的な回避）が今も続いているか。済んだもの・変わったものは消す。
   - **置き場所**：
     - グローバル（`~/.claude/CLAUDE.md`。Codex・Cursor の写しも）：どのプロジェクトでも同じに効く（返答の言語、道具の使い方、git の作法）
     - リポジトリの AGENTS.md：そのリポジトリで作業する全員（人・Claude・Codex）が毎回守る
     - メモリ：この利用者とのあいだの好みと経緯
     - 同じことが2か所にあれば、1か所に寄せ、もう片方は消す
   - **ぶつかり**：同じ場面で両方は守れない組。条件を付けて場面を分けるか、どちらかを消す。
   - **重複**：別の言葉で同じことを書いているもの。1つにまとめる。
3. **案を表で出す.** 「ルール（ファイル:行）｜見立て｜案（消す・書き直す・上げる・下ろす・まとめる）｜理由」。手を入れるものだけを並べ、そのままのものは件数だけ書く。
4. **承認されたものだけ直す.** AGENTS.md はそのリポジトリのコミットにする。メモリを消す・名前を変えるときは `MEMORY.md` の索引も直す。グローバルを変えたら Codex・Cursor の写しにも写す。
5. **1往復で止める.** 直したあとに、もう一度棚卸しを回さない。迷ったら「そのまま」。ルールの数を減らすこと自体を目標にしない。

## しないこと

- ぶつかりの判定を、正規表現やキーワードの組み合わせで自動にしない。意味で決まる。
- 棚卸しを定期では回さない。頼まれたとき、振る舞いがおかしいときだけ。
